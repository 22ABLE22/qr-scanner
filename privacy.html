Privacy

Last updated 26 October 2026.

What happens to your image

Nothing leaves the tab. The file is opened with the browser File API, drawn onto a canvas, and the pixels are handed to a decoder that runs in the same page. There is no upload endpoint anywhere in the code, so there is no server that could receive a picture.

What is stored

  • No cookies, no local storage, no session storage.
  • No analytics, no pixels, no third party scripts.
  • A service worker caches the page and the decoder files so the tool works offline. The cache holds code only, never an image you dropped.

Network requests the page makes

On a first visit it fetches its own files from the same origin: HTML, one font, the stylesheet, jsQR.js, and the service worker. The 1 MB WebAssembly engine is fetched only if the fast decoder fails on your image. There are no calls to any other host.

Camera

The camera is opened only after you press the camera button, and the permission prompt comes from your browser. Frames are decoded in memory and discarded. Closing the panel stops the tracks immediately.

Links you open

Opening a decoded link leaves this site and is subject to that site's own policy. Links open with rel="noopener noreferrer", so the destination does not learn where you came from.
